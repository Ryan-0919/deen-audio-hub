# 商城接口设计文档

## 1. 文档目标

本文件用于把商城一期后端接口统一下来，直接指导以下工作：

- 后端路由拆分
- 前端页面联调
- 后台管理端表单接线
- 支付回调对接

本稿以当前项目已有风格为基准，沿用现有接口组织方式：

- 用户端接口挂到 `/api/user`
- 后台端接口挂到 `/api/admin`
- 支付回调接口单独挂到 `/api/payment`

## 2. 通用约定

### 2.1 路由前缀

- 用户端商城接口前缀：`/api/user/shop`
- 后台端商城接口前缀：`/api/admin/shop`
- 支付回调接口前缀：`/api/payment`

### 2.2 鉴权方式

- 用户端接口：沿用现有 `Authorization: Bearer <token>`
- 后台端接口：沿用现有 `Authorization: Bearer <token>`
- 支付回调接口：不走用户或后台 JWT，改为支付平台签名校验

### 2.3 返回结构

商城接口保持和现有项目一致：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

失败时示意：

```json
{
  "code": 400,
  "message": "请求失败",
  "data": null
}
```

### 2.4 分页约定

列表接口统一支持：

- `page`
- `pageSize`

统一返回：

```json
{
  "list": [],
  "pagination": {
    "page": 1,
    "pageSize": 20,
    "total": 0
  }
}
```

### 2.5 一期状态枚举

接口层建议统一透出以下关键状态：

- 商品状态：`draft`、`on_sale`、`off_sale`
- 商品类型：`virtual`、`physical`、`hybrid`
- 订单状态：`pending_payment`、`paid`、`partially_fulfilled`、`completed`、`cancelled`、`refunding`、`refunded`
- 支付状态：`unpaid`、`paid`、`failed`、`refunded`
- 数字履约状态：`pending`、`success`、`failed`
- 发货状态：`pending`、`shipped`、`in_transit`、`signed`、`failed`

### 2.6 一期支付渠道约定

为了符合当前项目“移动端直接进入微信或支付宝支付，不走网页二维码收银台”的目标，一期支付渠道统一约定为：

- `wechat_jsapi`
- `wechat_h5`
- `alipay_wap`

明确不做：

- 网页二维码支付
- 支付宝电脑网站支付
- PC 收银台支付页

前端环境策略建议：

- 微信内打开：只走 `wechat_jsapi`
- 普通手机浏览器打开：可选 `wechat_h5` 或 `alipay_wap`
- PC 浏览器打开：一期直接提示“请在手机打开完成支付”

## 3. 用户端商城接口

### 3.1 商城首页

#### `GET /api/user/shop/home`

用途：

- 获取商城首页 Banner、推荐商品、分类入口、专题区块

返回建议字段：

```json
{
  "banners": [
    {
      "id": "banner_1",
      "imageUrl": "",
      "linkType": "product",
      "linkTarget": "product_id"
    }
  ],
  "featuredCategories": [],
  "featuredProducts": [],
  "courseProducts": [],
  "physicalProducts": [],
  "hybridProducts": []
}
```

### 3.2 分类列表

#### `GET /api/user/shop/categories`

用途：

- 获取商城可见分类

查询参数：

- `includeEmpty`

返回字段建议：

- `id`
- `name`
- `iconUrl`
- `sortOrder`
- `productCount`

### 3.3 商品列表

#### `GET /api/user/shop/products`

用途：

- 按分类、类型、关键词查询商品列表

查询参数：

- `categoryId`
- `type`
- `keyword`
- `sortBy`
- `page`
- `pageSize`

`sortBy` 一期建议支持：

- `default`
- `sales_desc`
- `price_asc`
- `price_desc`
- `latest`

返回字段建议：

- `id`
- `name`
- `subtitle`
- `coverUrl`
- `type`
- `minPrice`
- `maxPrice`
- `originalPrice`
- `salesCount`
- `requiresShipping`
- `tags`

### 3.4 商品详情

#### `GET /api/user/shop/products/:productId`

用途：

- 获取商品详情、图片、SKU、绑定课程摘要、购买说明

返回建议字段：

```json
{
  "id": "prod_xxx",
  "name": "课程商品",
  "subtitle": "副标题",
  "type": "hybrid",
  "status": "on_sale",
  "coverUrl": "",
  "images": [],
  "description": "",
  "detailContent": "",
  "purchaseNotice": "",
  "requiresShipping": true,
  "salesCount": 123,
  "skus": [
    {
      "id": "sku_xxx",
      "name": "默认规格",
      "price": "199.00",
      "originalPrice": "299.00",
      "stock": 100,
      "isDefault": true
    }
  ],
  "boundCourses": [
    {
      "id": "course_xxx",
      "name": "民法精讲"
    }
  ]
}
```

规则说明：

- 下架商品前台不可访问
- 删除商品前台不可访问
- 纯实物商品 `boundCourses` 返回空数组

### 3.5 购物车列表

#### `GET /api/user/shop/cart`

用途：

- 获取当前用户购物车

返回字段建议：

```json
{
  "items": [
    {
      "id": "cart_xxx",
      "productId": "prod_xxx",
      "productName": "商品名称",
      "productType": "virtual",
      "coverUrl": "",
      "skuId": "sku_xxx",
      "skuName": "默认规格",
      "price": "199.00",
      "quantity": 1,
      "selected": true,
      "stock": 20,
      "subtotal": "199.00",
      "requiresShipping": false
    }
  ],
  "summary": {
    "selectedCount": 1,
    "selectedAmount": "199.00"
  }

```

### 3.6 加入购物车

#### `POST /api/user/shop/cart/items`

请求字段：

- `productId`
- `skuId`
- `quantity`

规则：

- 同用户同 `skuId` 已存在则累加数量
- 校验商品状态和 SKU 状态
- 校验库存

### 3.7 修改购物车商品

#### `PATCH /api/user/shop/cart/items/:itemId`

请求字段：

- `quantity`
- `selected`

说明：

- 一期允许同一个接口同时改数量和选中状态
- `quantity <= 0` 时直接返回错误，不隐式删除

### 3.8 删除购物车商品

#### `DELETE /api/user/shop/cart/items/:itemId`

用途：

- 删除单个购物车商品

### 3.9 批量更新购物车选中状态

#### `PATCH /api/user/shop/cart/selection`

请求字段：

```json
{
  "itemIds": ["cart_1", "cart_2"],
  "selected": true
}
```

用途：

- 全选
- 反选
- 批量勾选去结算

### 3.10 地址列表

#### `GET /api/user/shop/addresses`

返回字段建议：

- `id`
- `name`
- `phone`
- `province`
- `city`
- `district`
- `address`
- `isDefault`

### 3.11 新增地址

#### `POST /api/user/shop/addresses`

请求字段：

- `name`
- `phone`
- `province`
- `city`
- `district`
- `address`
- `isDefault`

规则：

- 若用户首次新增地址，可自动设为默认地址
- 若 `isDefault = true`，需把该用户其他地址改为非默认

### 3.12 修改地址

#### `PATCH /api/user/shop/addresses/:addressId`

用途：

- 编辑收货地址

### 3.13 删除地址

#### `DELETE /api/user/shop/addresses/:addressId`

规则：

- 已被待支付订单引用的地址不影响订单快照
- 删除地址只删地址表，不动历史订单

### 3.14 提交订单预览

#### `POST /api/user/shop/checkout/preview`

请求方式：

- 支持 `cartItemIds`
- 支持 `buyNowSkuId + quantity`

请求示意：

```json
{
  "cartItemIds": ["cart_1", "cart_2"],
  "addressId": "addr_xxx"
}
```

返回建议字段：

- `items`
- `productAmount`
- `freightAmount`
- `discountAmount`
- `payAmount`
- `requiresShipping`
- `address`
- `warnings`

用途：

- 结算前重新校验价格、库存、上下架状态

### 3.15 提交订单

#### `POST /api/user/shop/orders`

请求字段：

- `source`
- `cartItemIds`
- `buyNowSkuId`
- `buyNowQuantity`
- `addressId`
- `remark`
- `payChannel`

`source` 一期建议支持：

- `cart`
- `buy_now`

`payChannel` 一期建议支持：

- `wechat_jsapi`
- `wechat_h5`
- `alipay_wap`

返回字段建议：

```json
{
  "orderId": "order_xxx",
  "orderNo": "SO202604160001",
  "status": "pending_payment",
  "paymentStatus": "unpaid",
  "payAmount": "199.00",
  "payExpireAt": "2026-04-16 18:00:00"
}
```

### 3.16 获取支付参数

#### `GET /api/user/shop/orders/:orderId/pay`

用途：

- 获取当前订单可用支付参数
- 根据当前支付渠道返回微信或支付宝的平台内拉起参数
- 不返回网页二维码支付内容

返回字段建议：

```json
{
  "orderId": "order_xxx",
  "orderNo": "SO202604160001",
  "channel": "wechat_jsapi",
  "payAmount": "199.00",
  "expireAt": "2026-04-16 18:00:00",
  "paymentParams": {}
}
```

`paymentParams` 说明：

- `wechat_jsapi`：返回微信 JSAPI 所需参数
- `wechat_h5`：返回微信 H5 支付跳转参数
- `alipay_wap`：返回支付宝 WAP 表单或跳转参数

接口处理建议：

- 若用户在微信内请求 `alipay_wap`，直接返回不可支付提示
- 若用户在 PC 浏览器请求 `wechat_h5` 或 `alipay_wap`，直接返回“请在手机打开”

### 3.17 订单列表

#### `GET /api/user/shop/orders`

查询参数：

- `status`
- `page`
- `pageSize`

前台映射状态建议：

- `all`
- `pending_payment`
- `pending_shipment`
- `shipped`
- `completed`
- `cancelled`

返回字段建议：

- `id`
- `orderNo`
- `status`
- `paymentStatus`
- `payAmount`
- `createdAt`
- `items`
- `digitalFulfillmentStatus`
- `shipmentStatus`

### 3.18 订单详情

#### `GET /api/user/shop/orders/:orderId`

返回建议字段：

- 订单基础信息
- 商品快照信息
- 地址快照
- 支付信息
- 数字履约信息
- 发货信息
- 物流轨迹摘要
- 可执行操作按钮状态

### 3.19 取消订单

#### `POST /api/user/shop/orders/:orderId/cancel`

请求字段：

- `reason`

规则：

- 仅 `pending_payment` 状态允许取消
- 取消后释放预占库存

### 3.20 确认收货

#### `POST /api/user/shop/orders/:orderId/confirm-receipt`

规则：

- 仅已发货订单可确认收货
- 纯虚拟订单不显示该操作
- 组合商品需在实物部分收货后才可整体完成

### 3.21 查询物流详情

#### `GET /api/user/shop/orders/:orderId/logistics`

返回字段建议：

- `shipmentId`
- `company`
- `trackingNo`
- `status`
- `tracks`

## 5. 支付接口

### 5.1 发起支付

#### `POST /api/payment/create`

说明：

- 一期也可以不单独做该接口，直接由 `GET /api/user/shop/orders/:orderId/pay` 内部完成
- 若后续渠道变多，建议单独抽为支付中心接口

### 5.2 支付回调

#### `POST /api/payment/callback/:channel`

用途：

- 接收微信、支付宝等平台异步通知

处理要求：

- 验签
- 按 `orderNo` 查询订单
- 校验支付金额
- 幂等更新 `ShopPaymentRecord`
- 推进订单状态
- 触发课程开通和发货待处理状态

一期回调渠道建议为：

- `/api/payment/callback/wechat_jsapi`
- `/api/payment/callback/wechat_h5`
- `/api/payment/callback/alipay_wap`

详细规则见：

- `09-商城支付与回调设计.md`

## 7. 一期优先实现顺序

建议后端接口实施顺序：

1. 分类与商品后台接口
2. 用户端商品列表与详情接口
3. 地址与购物车接口
4. 提交订单与订单列表接口
5. 支付回调与自动开课
6. 发货、物流、后台订单处理接口
