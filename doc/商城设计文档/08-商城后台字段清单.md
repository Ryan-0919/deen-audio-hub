# 商城后台字段清单

## 1. 文档目的

本文件用于把商城后台页面涉及的字段做成统一清单，方便：

- 后台表单开发
- 接口字段对齐
- 测试用例编写
- 后续产品迭代补字段

## 2. 商城分类字段

### 2.1 分类列表字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 是 | 分类 ID |
| `name` | string | 是 | 分类名称，建议 2 到 20 字 |
| `iconUrl` | string | 否 | 分类图标 |
| `sortOrder` | number | 是 | 排序值，越小越靠前 |
| `status` | boolean | 是 | 是否启用 |
| `productCount` | number | 否 | 当前分类下商品数量 |
| `createdAt` | datetime | 否 | 创建时间 |
| `updatedAt` | datetime | 否 | 更新时间 |

### 2.2 分类编辑表单字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `name` | string | 是 | 分类名称 |
| `iconUrl` | string | 否 | 分类图标地址 |
| `sortOrder` | number | 是 | 排序 |
| `status` | boolean | 是 | 启用或停用 |

## 3. 商品基础信息字段

### 3.1 商品主表字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `categoryId` | string | 是 | 商品所属分类 |
| `name` | string | 是 | 商品名称，建议 5 到 60 字 |
| `subtitle` | string | 否 | 商品副标题 |
| `type` | enum | 是 | `virtual`、`physical`、`hybrid` |
| `status` | enum | 是 | `draft`、`on_sale`、`off_sale` |
| `coverUrl` | string | 是 | 主封面图片 |
| `coverObjectKey` | string | 否 | OSS 对象 Key |
| `description` | string | 否 | 简要描述 |
| `detailContent` | string | 否 | 富文本详情 |
| `purchaseNotice` | string | 否 | 购买须知 |
| `sortOrder` | number | 是 | 排序 |
| `requiresShipping` | boolean | 是 | 是否需要发货 |
| `shippingFee` | decimal | 否 | 固定运费 |
| `freeShippingThreshold` | decimal | 否 | 满额包邮阈值 |
| `salesCount` | number | 否 | 销量，后台展示只读 |

### 3.2 商品字段联动规则

- 当 `type = virtual` 时，`requiresShipping` 必须为 `false`
- 当 `type = physical` 时，不允许绑定课程
- 当 `type = hybrid` 时，必须同时配置课程与发货属性
- 当商品上架时，至少要有 1 个有效 SKU

## 4. 商品图片字段

### 4.1 主图与轮播图

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `coverUrl` | string | 是 | 商品主图 |
| `images[].imageUrl` | string | 是 | 轮播图图片地址 |
| `images[].imageObjectKey` | string | 否 | 图片 OSS Key |
| `images[].sortOrder` | number | 是 | 图片排序 |

### 4.2 建议规则

- 主图建议固定 1 张
- 轮播图建议 1 到 6 张
- 图片比例建议统一，避免前台布局抖动

## 5. SKU 字段

### 5.1 SKU 列表字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 否 | 编辑时存在 |
| `name` | string | 是 | SKU 名称，如“标准版” |
| `price` | decimal | 是 | 售价 |
| `originalPrice` | decimal | 否 | 原价 |
| `stock` | number | 是 | 库存 |
| `weight` | number | 否 | 重量，单位建议为克 |
| `status` | boolean | 是 | SKU 是否启用 |
| `isDefault` | boolean | 是 | 是否默认规格 |

### 5.2 SKU 校验规则

- 同一商品下至少保留 1 个 SKU
- 同一商品下只能有 1 个默认 SKU
- `price` 必须大于 0
- `stock` 不能小于 0
- 下架商品可保留 SKU，但前台不可售

## 6. 商品绑定课程字段

### 6.1 课程绑定区字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `courseIds` | string[] | 条件必填 | 商品绑定的课程 ID 列表 |
| `courseNames` | string[] | 否 | 前台和后台显示用 |
| `grantMode` | string | 否 | 一期固定为 `course_permission` |

### 6.2 规则说明

- `virtual` 和 `hybrid` 商品可绑定一个或多个课程
- `physical` 商品绑定课程必须为空
- 若绑定多个课程，支付成功后全部发放
- 已存在的课程权限不重复发放

## 7. 发货与运费字段

### 7.1 发货属性字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `requiresShipping` | boolean | 是 | 是否需要发货 |
| `shippingFee` | decimal | 否 | 固定运费 |
| `freeShippingThreshold` | decimal | 否 | 满多少包邮 |
| `weight` | number | 否 | 用于后续扩展重量计费 |

### 7.2 一期建议

- 一期先使用固定运费或满额包邮
- 不先做复杂运费模板
- 不先做多仓、多地区差异运费

## 12. 建议的表单校验规则

- 名称类字段统一做首尾空格裁剪
- 金额保留两位小数
- 运费、价格、库存都不能为负数
- 商品上架前必须完成封面、SKU、分类、类型配置
- 需要发货的商品上架前必须具备有效运费配置
- 绑定课程的商品上架前必须至少绑定 1 门课程

- 满额包邮阈值
- 发货备注
- 商城说明文案

## 14. 使用建议

该字段清单建议作为后台页面、接口 DTO、数据库字段对齐的中间层文档使用。

实际编码时，优先保持三层一致：

- 页面字段名
- 接口字段名
- Prisma 模型字段名

只有这样，后续商城功能继续扩展时，返工成本才会低。
