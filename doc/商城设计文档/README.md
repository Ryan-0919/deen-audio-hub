# 商城设计文档

## 目录说明

本目录用于沉淀当前项目后续要新增的统一商城设计方案。商城并不拆成“虚拟商城”和“实物商城”两套系统，而是采用统一商品、统一订单、分履约方式处理的设计。

## 文档列表

- `01-商城总体设计.md`
  说明商城定位、商品类型、用户端和后台端页面结构、一期建设范围。
- `02-商城业务流程与履约设计.md`
  说明下单、支付、开通课程、发货、物流、退款、状态流转等关键业务流程。
- `03-商城数据库设计草案.md`
  说明商城新增的数据模型、字段建议、与现有音频课程系统的关联关系。
- `04-商城Prisma建模初稿.md`
  将数据库草案进一步收敛为接近可执行的 Prisma 模型命名与关系稿。
- `05-商城页面原型文档.md`
  说明用户端与后台端一期页面原型、页面模块、字段与交互路径。
- `06-商城接口设计文档.md`
  固化用户端、后台端、支付回调相关接口的 URL、参数和返回结构。
- `07-商城一期开发排期.md`
  说明商城一期的里程碑、开发顺序、交付物、联调与上线安排。
- `08-商城后台字段清单.md`
  汇总后台分类、商品、订单、发货、商城配置等页面的字段清单。
- `09-商城支付与回调设计.md`
  说明支付单、回调验签、幂等、自动开课、发货触发与对账策略。
- `10-商城支付体系设计.md`
  从交易模型、支付渠道、状态机、退款、对账、风控到代码分层，完整说明商城支付体系。

## 设计原则

- 一个商城同时支持纯虚拟、纯实物、虚拟加实物组合商品
- 课程权限发放复用现有 `UserCoursePermission`
- 课程开放状态仍按现有课程系统控制，不因购买即强制显示
- 商城交易、履约、物流分层设计，避免与课程学习逻辑耦合
- 一期优先实现可上线收款、自动开课、后台发货、用户查看订单和物流
