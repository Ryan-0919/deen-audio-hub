# 商城真实支付接入配置说明

## 1. 当前已接入能力

本次商城支付已从 `mock` 扩展为真实支付网关模式，支持：

- 微信支付 `wechat_h5`
- 微信支付 `wechat_jsapi`
- 支付宝 `alipay_wap`

同时已补齐：

- 用户发起支付
- 微信 OAuth 获取 `openid`
- 微信/支付宝异步回调
- 回调验签
- 支付成功后的订单入账
- 课程权限自动开通
- 前端支付回跳页
- 回跳后的主动查单补偿

## 2. 运行模式

`.env` 中通过以下变量切换：

```env
SHOP_PAYMENT_MODE=gateway
```

可选值：

- `mock`
- `gateway`

只有 `gateway` 模式下才会真正请求微信/支付宝。

## 3. 必填环境变量

### 3.1 公共地址

```env
PAY_SITE_BASE_URL=https://你的站点域名
PAY_NOTIFY_BASE_URL=https://你的站点域名
```

说明：

- `PAY_SITE_BASE_URL` 用于前端支付回跳页
- `PAY_NOTIFY_BASE_URL` 用于支付平台回调地址
- 如果前后端共域，两个值通常相同

### 3.2 微信支付

```env
WECHAT_PAY_APP_ID=
WECHAT_PAY_APP_SECRET=
WECHAT_PAY_MCH_ID=
WECHAT_PAY_MCH_SERIAL_NO=
WECHAT_PAY_API_V3_KEY=
WECHAT_PAY_PRIVATE_KEY_PATH=
WECHAT_PAY_PLATFORM_CERT_PATH=
WECHAT_PAY_PLATFORM_SERIAL=
WECHAT_PAY_H5_APP_NAME=得恩法考
WECHAT_PAY_H5_APP_URL=https://你的站点域名
```

也支持直接把 PEM 内容写进环境变量：

```env
WECHAT_PAY_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----"
WECHAT_PAY_PLATFORM_CERT="-----BEGIN CERTIFICATE-----\n...\n-----END CERTIFICATE-----"
```

字段说明：

- `WECHAT_PAY_APP_ID`: 公众号或对应应用的 `appid`
- `WECHAT_PAY_APP_SECRET`: 微信内 `JSAPI` 获取 `openid` 必需
- `WECHAT_PAY_MCH_ID`: 商户号
- `WECHAT_PAY_MCH_SERIAL_NO`: 商户 API 证书序列号
- `WECHAT_PAY_API_V3_KEY`: 微信支付 API v3 密钥，长度必须 32 位
- `WECHAT_PAY_PRIVATE_KEY_PATH`: 商户私钥 PEM 文件路径
- `WECHAT_PAY_PLATFORM_CERT_PATH`: 微信支付平台证书 PEM 文件路径
- `WECHAT_PAY_PLATFORM_SERIAL`: 平台证书序列号，可选但建议配置

### 3.3 支付宝

```env
ALIPAY_APP_ID=
ALIPAY_PRIVATE_KEY_PATH=
ALIPAY_PUBLIC_KEY_PATH=
ALIPAY_GATEWAY=https://openapi.alipay.com/gateway.do
```

也支持直接写 PEM 内容：

```env
ALIPAY_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----"
ALIPAY_PUBLIC_KEY="-----BEGIN PUBLIC KEY-----\n...\n-----END PUBLIC KEY-----"
```

## 4. 回调地址

系统实际使用的回调地址如下：

- 微信 H5: `/api/payment/callback/wechat_h5`
- 微信 JSAPI: `/api/payment/callback/wechat_jsapi`
- 支付宝 WAP: `/api/payment/callback/alipay_wap`
- 微信 OAuth 回跳: `/api/payment/wechat/oauth/callback`

如果你的线上域名是 `https://denfk.vip`，则需要在支付平台配置：

- `https://denfk.vip/api/payment/callback/wechat_h5`
- `https://denfk.vip/api/payment/callback/wechat_jsapi`
- `https://denfk.vip/api/payment/callback/alipay_wap`
- `https://denfk.vip/api/payment/wechat/oauth/callback`

## 5. 前端支付路径

### 5.1 微信内打开

流程：

1. 选择 `wechat_jsapi`
2. 若本地没有 `openid`，后端返回微信 OAuth 地址
3. 微信授权成功后回跳 `/user/shop/payment/return`
4. 前端重新发起 `JSAPI` 支付
5. 调用 `WeixinJSBridge`
6. 回到支付回跳页并轮询订单状态

### 5.2 手机浏览器打开

可走：

- `wechat_h5`
- `alipay_wap`

两者都会直接跳转到各自平台内支付，不会生成网页二维码。

### 5.3 PC 浏览器

当前服务端会限制：

- 微信 H5 只允许手机浏览器
- 支付宝 WAP 只允许手机浏览器
- 微信 JSAPI 只允许微信内

## 6. 订单状态确认

系统现在有三层确认机制：

1. 支付平台异步回调
2. 回跳页主动查单
3. 用户进入订单详情时可继续重试支付

因此即使回调有延迟，用户通常也能在回跳页看到最终状态。

## 7. 上线建议顺序

建议按下面顺序上线：

1. 先在线上配置好所有支付环境变量
2. 确认 Nginx 已放通 `/api/payment/*`
3. 重启 API 服务
4. 先用支付宝 WAP 做一笔小额测试
5. 再验证微信 H5
6. 最后在微信内验证 JSAPI

## 8. 已知边界

- 目前使用单平台证书配置，若微信平台证书轮换，需要同步更新
- 主动查单目前仅做支付成功确认，不做完整对账
- 退款、账单下载、异常补偿后台还未继续展开
