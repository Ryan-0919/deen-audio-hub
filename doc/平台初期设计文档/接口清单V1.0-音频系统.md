# 音频系统接口清单 V1.0

## 1. 文档说明

本文档用于梳理音频系统当前版本的接口清单，作为前后端联调、接口开发和测试对接的依据。

本文档重点描述：

- 接口模块划分
- 接口用途
- 请求参数概要
- 返回内容概要
- 关键业务规则

本文档不包含：

- 数据库表设计
- 字段类型级别的最终接口协议
- 加密签名细节
- 代码实现

## 2. 接口分组

本系统接口建议分为以下 8 组：

1. 认证与登录接口
2. 用户端课程接口
3. 用户端播放器接口
4. 后台用户管理接口
5. 后台设备管理接口
6. 后台课程管理接口
7. 后台音频库接口
8. 系统配置与通知接口

## 3. 通用约定

### 3.1 鉴权方式

- 用户端接口：用户登录后携带登录态访问
- 后台接口：管理员登录后携带后台登录态访问

### 3.2 通用返回建议

所有接口建议统一返回：

- `code`：业务状态码
- `message`：提示信息
- `data`：业务数据

### 3.3 分页接口建议

列表类接口建议统一支持：

- `page`
- `pageSize`

并返回：

- `list`
- `total`

### 3.4 时间字段建议

所有时间字段建议统一返回标准时间格式，避免前后端各自处理导致歧义。

## 4. 认证与登录接口

## 4.1 用户登录

接口用途：

- 用户使用手机号和密码登录系统

请求参数概要：

- 手机号
- 密码
- 设备标识
- 设备类型
- 设备型号
- IP

返回内容概要：

- 用户基础信息
- 登录态信息
- 当前设备数量

关键规则：

- 用户状态为停用时，不允许登录
- 第 4 台设备登录时，不允许登录
- 同一设备重复登录，不新增设备数量

## 4.2 用户退出登录

接口用途：

- 用户主动退出登录

请求参数概要：

- 当前登录态标识
- 当前设备标识

返回内容概要：

- 退出结果

关键规则：

- 退出成功后，当前设备名额自动释放

## 4.3 获取当前登录用户信息

接口用途：

- 获取当前登录用户基础资料

返回内容概要：

- 用户手机号
- 用户状态
- 最近登录时间

## 5. 用户端课程接口

## 5.1 获取我的课程列表

接口用途：

- 获取当前用户有权限且已开放的课程列表

请求参数概要：

- 排序方式，可默认不传

返回内容概要：

- 课程 ID
- 课程封面
- 课程名称
- 课程简介
- 课程开放时间

关键规则：

- 未开放课程不返回
- 仅返回当前用户有权限的课程
- 默认按课程开放时间倒序

## 5.2 获取课程详情

接口用途：

- 获取课程基础信息、标签列表和默认标签内容

请求参数概要：

- 课程 ID

返回内容概要：

- 课程基础信息
- 标签列表
- 默认标签 ID
- 默认标签下音频列表

关键规则：

- 标签按后台拖拽顺序返回
- 默认返回第一个标签内容
- 空标签也返回

## 5.3 获取指定标签下音频列表

接口用途：

- 切换标签时获取对应标签下的音频内容

请求参数概要：

- 课程 ID
- 标签 ID

返回内容概要：

- 标签信息
- 音频列表

音频列表建议字段：

- 音频 ID
- 音频名称
- 时长
- 是否学完
- 上次播放进度

关键规则：

- 空标签返回空列表
- 前端显示 `暂无课程`

## 6. 用户端播放器接口

## 6.1 获取音频播放详情

接口用途：

- 进入播放器页时获取当前音频完整播放信息

请求参数概要：

- 课程 ID
- 音频 ID

返回内容概要：

- 音频标题
- 课程名称
- 标签名称
- 音频播放地址
- 总时长
- 文案内容
- 上次播放进度
- 上一条音频信息
- 下一条音频信息

关键规则：

- 只允许访问用户有权限且课程已开放的音频
- 如果音频无文案，不应出现在可播放列表中

## 6.2 保存播放进度

接口用途：

- 用户退出或切换音频时保存当前播放进度

请求参数概要：

- 课程 ID
- 音频 ID
- 当前播放秒数
- 总时长

返回内容概要：

- 保存结果

关键规则：

- 再次进入该音频时，从上次保存位置恢复

## 6.3 标记学习完成

接口用途：

- 音频播放完成或进度条拖到末尾时标记学完

请求参数概要：

- 课程 ID
- 音频 ID

返回内容概要：

- 标记结果

关键规则：

- 播放完成算学完
- 拖动到末尾也算学完

## 6.4 获取播放器上一条/下一条信息

接口用途：

- 用于播放器切换上一条和下一条

请求参数概要：

- 课程 ID
- 当前音频 ID

返回内容概要：

- 上一条音频信息
- 下一条音频信息

关键规则：

- 当前标签播完后，下一条取下一个标签的第一条
- 顺序按标签顺序和标签内排序计算

请求参数概要：

- pageSize

返回内容概要：

- 拥有课程权限
- 设备数量
- 用户状态

## 7.2 单个新增用户

接口用途：

- 后台新增单个用户

请求参数概要：

- 手机号
- 课程权限列表

返回内容概要：

- 新增结果
- 是否为新建账号
- 是否为已有账号追加权限

关键规则：

- 已存在手机号时，不重复建号，只追加权限
- 默认密码为 `den2024`

## 7.3 批量新增用户

## 7.4 编辑用户课程权限

请求参数概要：

- 用户 ID

返回内容概要：

- 修改结果

关键规则：

## 7.5 批量添加课程权限

接口用途：

请求参数概要：

- 用户 ID 列表

返回内容概要：

- 执行结果

## 7.6 启用用户

返回内容概要：

请求参数概要：

返回内容概要：

- 停用结果

## 7.8 批量启用用户

接口用途：

## 7.9 批量停用用户

- 批量停用多个用户

## 7.11 批量删除用户

接口用途：

- 批量删除多个用户

请求参数概要：

- 用户 ID 列表

## 7.12 管理员修改用户密码

接口用途：

- 后台修改指定用户密码

请求参数概要：

- 新密码

返回内容概要：

- 修改结果

关键规则：
