# Figma原型页面清单与线框图 V1.0

## 1. 文档说明

本文档用于直接指导 Figma 原型搭建，基于当前已确认的产品方案、开发方案、接口清单和原型说明文档整理。

本文件的目标是让设计或产品人员可以直接按本文档创建 Figma 页面、画板、组件和线框图。

本期终端方向：

- 用户端：手机端优先
- 后台管理端：桌面端优先

## 2. Figma 文件结构建议

建议 Figma 文件按以下页面组织：

1. `00-封面与说明`
2. `01-全局样式`
3. `02-全局组件`
4. `03-用户端-Mobile`
5. `04-后台管理-Desktop`
6. `05-弹窗与抽屉`
7. `06-状态页`

## 3. 画板尺寸建议

## 3.1 用户端画板

建议统一使用：

- `390 x 844`

适用场景：

- 登录页
- 我的课程页
- 课程详情页
- 音频播放器页

## 3.2 后台管理端画板

建议统一使用：

- `1440 x 1024`

适用场景：

- 后台列表页
- 编辑页
- 内容编排页
- 音频库页

## 3.3 弹窗与抽屉尺寸

建议统一：

- 中型弹窗：`560 x 640`
- 大型弹窗：`720 x 760`
- 右侧抽屉：宽 `420` 或 `480`

## 4. 栅格与间距建议

## 4.1 用户端

- 左右边距：`16`
- 模块上下间距：`16`
- 卡片圆角：`16`
- 主按钮高度：`48`
- 标签高度：`32`

## 4.2 后台管理端

- 页面左右边距：`24`
- 模块上下间距：`16`
- 表格上方操作栏间距：`12`
- 筛选区高度建议：`72` 到 `96`
- 表格圆角：`12`

## 5. Figma 命名规范建议

## 5.1 页面命名

- `M01-登录页`
- `M02-我的课程`
- `M03-课程详情`
- `M04-音频播放器`
- `D01-后台登录`
- `D02-用户列表`
- `D03-批量导入用户`
- `D04-课程列表`
- `D05-新建课程`
- `D06-编辑课程`
- `D07-课程内容编排`
- `D08-音频库`

## 5.2 组件命名

- `Header/Mobile`
- `Card/Course`
- `Tab/Course`
- `ListItem/Audio`
- `Player/Control`
- `Table/User`
- `Table/Course`
- `Sidebar/Admin`
- `Modal/Base`
- `Drawer/Device`

## 6. 全局组件建议

建议先在 Figma 中建立以下基础组件：

- 按钮：主按钮、次按钮、危险按钮、文字按钮
- 输入框：默认、错误、禁用
- 标签：默认、选中、空状态
- 卡片：课程卡片、信息卡片
- 列表项：音频列表项、表格行
- 表格：后台通用表格
- 弹窗：确认弹窗、表单弹窗
- 抽屉：设备管理抽屉
- 状态块：空状态、错误状态、加载状态

## 10. Figma 搭建顺序建议

后台连线：

- 用户列表 -> 新增用户弹窗

- 课程列表 -> 新建课程

- 内容编排页 -> 引用音频弹窗
